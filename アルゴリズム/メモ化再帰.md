
同じ状態を何度も再計算する再帰で、計算結果を保存して再利用する。
この例はDAGなど、再帰の遷移に循環がない場合を前提とする。循環がある場合は別途状態管理が必要。

```cpp
vector<ll> memo(n, -1);

auto dfs = [&](auto&& self, int v) -> ll {
    if (memo[v] != -1) return memo[v];

    ll res = 0;

    for (int nv : g[v]) {
        res = max(res, self(self, nv) + 1);
    }

    return memo[v] = res;
};
```

`-1` が正しい答えとして出る場合は、別に `visited` を持つ。

「状態数 × 各状態からの遷移数」まで計算量を落とせることが多い。
