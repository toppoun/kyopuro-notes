
木は N 頂点 N-1 辺で、任意の2頂点間の経路が1通りだけ存在する。

DFSするときは「親へ戻らない」だけでよい。

## 親と深さ

```cpp
vector<int> parent(n, -1);
vector<int> depth(n);

auto dfs = [&](auto&& self, int v, int p) -> void {
    parent[v] = p;

    for (int nv : g[v]) {
        if (nv == p) continue;

        depth[nv] = depth[v] + 1;
        self(self, nv, v);
    }
};

dfs(dfs, 0, -1);
```

## 部分木サイズ

`sub[v]` = v を根とした部分木の頂点数。

```cpp
vector<int> sub(n);

auto dfs = [&](auto&& self, int v, int p) -> void {
    sub[v] = 1;

    for (int nv : g[v]) {
        if (nv == p) continue;

        self(self, nv, v);
        sub[v] += sub[nv];
    }
};

dfs(dfs, 0, -1);
```

子を全部処理した後に結果を親へ足す。

## 木の距離

辺の重みがないなら、根からの距離は `depth` そのもの。

```cpp
depth[nv] = depth[v] + 1;
```

重み付きなら

```cpp
dist[nv] = dist[v] + cost;
```

## 葉

根以外で次数1なら葉。

```cpp
if (v != root && g[v].size() == 1) {
    // 葉
}
```

## 覚え方

一般グラフ:
`seen` で訪問済み管理。

木:
親 `p` を持って `nv == p` を飛ばすだけで十分。
