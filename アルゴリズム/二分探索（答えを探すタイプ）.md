
配列を探す `lower_bound` ではなく、答え x に対する条件が単調なときに使う。

例: 「x 以上なら可能」が一度 true になった後ずっと true。

## 最小の true を探す

```cpp
ll ng = -1;
ll ok = INF;

auto f = [&](ll x) {
    // x で条件を満たすなら true
};

while (ok - ng > 1) {
    ll mid = ng + (ok - ng) / 2;

    if (f(mid)) {
        ok = mid;
    } else {
        ng = mid;
    }
}

cout << ok << '\n';
```

- `ng` は必ず false の値
- `ok` は必ず true の値
- 最後に `ok` が最小の true

最大の true を探すなら true / false 側を逆に考える。
