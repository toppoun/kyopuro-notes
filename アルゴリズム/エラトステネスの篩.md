
N 以下の素数をまとめて求める。

```cpp
vector<bool> is_prime(n + 1, true);

is_prime[0] = false;
if (n >= 1) is_prime[1] = false;

for (ll p = 2; p * p <= n; p++) {
    if (!is_prime[p]) continue;

    for (ll x = p * p; x <= n; x += p) {
        is_prime[x] = false;
    }
}
```

素数一覧が欲しいなら

```cpp
vector<int> primes;

for (int i = 2; i <= n; i++) {
    if (is_prime[i]) primes.push_back(i);
}
```

計算量 O(N log log N)。
