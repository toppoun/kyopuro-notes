
回文の中心展開を高速化し、各中心の回文半径を O(N) で求める。

N が大きい最長回文などで使う。

## 基本アイデア

今まで見つけた中で、最も右端まで伸びている回文区間 `[l, r]` を持つ。

i が `[l, r]` の中なら、反対側の調査済み中心から半径をもらう。

**鏡側から半径をもらう → r までで切る → 外側だけ調べる**

## d1: 奇数長

`d1[i]` は i を中心とする奇数長回文の半径。

中心自身も1として数える。

長さ:

```cpp
2 * d1[i] - 1
```

範囲:

```cpp
[i - d1[i] + 1, i + d1[i] - 1]
```

鏡側:

```cpp
l + r - i
```

## d2: 偶数長

`d2[i]` は `i - 1` と i の間を中心とする偶数長回文の半径。

長さ:

```cpp
2 * d2[i]
```

範囲:

```cpp
[i - d2[i], i + d2[i] - 1]
```

鏡側:

```cpp
l + r - i + 1
```

## 実戦コード

```cpp
int n = s.size();
vector<int> d1(n), d2(n);

int l = 0, r = -1;

for (int i = 0; i < n; i++) {
    int k = 1;

    if (i <= r) {
        int j = l + r - i;
        k = min(d1[j], r - i + 1);
    }

    while (i - k >= 0 && i + k < n && s[i - k] == s[i + k]) {
        k++;
    }

    d1[i] = k;

    if (i + k - 1 > r) {
        l = i - k + 1;
        r = i + k - 1;
    }
}

l = 0;
r = -1;

for (int i = 0; i < n; i++) {
    int k = 0;

    if (i <= r) {
        int j = l + r - i + 1;
        k = min(d2[j], r - i + 1);
    }

    while (i - k - 1 >= 0 && i + k < n && s[i - k - 1] == s[i + k]) {
        k++;
    }

    d2[i] = k;

    if (i + k - 1 > r) {
        l = i - k;
        r = i + k - 1;
    }
}
```

## 最長回文の長さ

```cpp
int ans = 0;

for (int i = 0; i < n; i++) {
    ans = max(ans, 2 * d1[i] - 1);
    ans = max(ans, 2 * d2[i]);
}
```

## 覚えるところ

奇数長:
- `d1[i]` は i が中心
- k は1から
- 鏡側は `l + r - i`

偶数長:
- `d2[i]` は `i - 1` と i の間が中心
- k は0から
- 鏡側は `l + r - i + 1`

共通:
- i が r の内側なら鏡側の半径を使う
- `r - i + 1` より外はまだ信用しない
- 外側だけ while で伸ばす
- r を超えたら l と r を更新する

N が小さいなら普通の中心展開、N が大きければ Manacher法。
