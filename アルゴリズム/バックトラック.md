
選択肢を1つ選ぶ → 再帰 → 元に戻す、を繰り返して全探索する。

```cpp
vector<int> cur;
vector<bool> used(n);

auto dfs = [&](auto&& self) -> void {
    if ((int)cur.size() == n) {
        // 1つの完成状態
        return;
    }

    for (int i = 0; i < n; i++) {
        if (used[i]) continue;

        used[i] = true;
        cur.push_back(i);

        self(self);

        cur.pop_back();
        used[i] = false;
    }
};

dfs(dfs);
```

重要なのは再帰から戻った後に状態を元に戻すこと。

途中で答えになり得ないと分かったら、その時点で return / continue して枝刈りする。
