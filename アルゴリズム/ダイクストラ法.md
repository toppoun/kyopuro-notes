
辺の重みが非負のグラフで単一始点最短距離を求める。

```cpp
vector<vector<pair<int, ll>>> g(n);
vector<ll> dist(n, INF);

priority_queue<
    pair<ll, int>,
    vector<pair<ll, int>>,
    greater<>
> pq;

dist[s] = 0;
pq.push({0, s});

while (!pq.empty()) {
    auto [d, v] = pq.top();
    pq.pop();

    if (d != dist[v]) continue;

    for (auto [nv, cost] : g[v]) {
        if (dist[nv] <= d + cost) continue;
        dist[nv] = d + cost;
        pq.push({dist[nv], nv});
    }
}
```

古い距離がheapに残るので `if (d != dist[v]) continue;` で捨てる。

計算量はだいたい O((V + E) log V)。

負の辺がある場合は使えない。
