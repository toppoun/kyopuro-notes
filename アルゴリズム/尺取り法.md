
連続部分列 `[l, r)` を保ちながら、l と r をそれぞれ右にしか動かさず探索する。

条件に単調性があると O(N) にできる。

## 典型: 和が K 以下の最長区間

配列の要素が非負なら使える。

```cpp
ll sum = 0;
int r = 0;
int ans = 0;

for (int l = 0; l < n; l++) {
    while (r < n && sum + a[r] <= k) {
        sum += a[r];
        r++;
    }

    ans = max(ans, r - l);

    if (r == l) {
        r++;
    } else {
        sum -= a[l];
    }
}
```

## 見方

現在の区間は `[l, r)`。

- 条件を満たす間 r を伸ばす
- これ以上伸ばせないところで答えを更新
- l を1つ進める
- r は左へ戻さない

r が全体で最大 N 回しか進まないので O(N)。

## 使える条件

「r を右へ伸ばすほど条件が厳しくなる」のような単調性が必要。

例えば「区間和 ≤ K」は要素が非負なら単調だが、負数があると単純な尺取りは使えない。

## よくある用途

- 和が K 以下の最長連続部分列
- 条件を満たす連続部分列の個数
- 種類数が K 以下
- 同じ値を含まない最長区間
