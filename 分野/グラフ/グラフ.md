# グラフ

頂点と辺で表した関係をたどり、到達可能性・連結性・距離を調べる分野。辺の向きと重み、始点の数、必要な距離の範囲で手法を選ぶ。

- 重みなしの最短距離は [BFS](../../アルゴリズム/BFS.md)
- 到達可能性や連結成分の探索は [DFS](../../アルゴリズム/DFS.md)
- 非負重みの単一始点最短距離は [ダイクストラ法](ダイクストラ法.md)
- 頂点数が小さい場合の全点対最短距離は [ワーシャルフロイド法](ワーシャルフロイド法.md)
- 辺を追加しながら連結性を管理するなら [Union-Find](../../アルゴリズム/Union-Find.md)
- 木やマス目の構造を使える場合は [木](../木/木.md) と [グリッド](../グリッド/グリッド.md) も参照する。
