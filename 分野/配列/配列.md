# 配列

添字を持つ要素列を走査・並べ替えし、区間の集計や更新を行う分野。配列の更新があるか、クエリをまとめて処理できるかで手法を選ぶ。

- 格納・走査は [vector / array](../../STL/vector-array.md)、整列・探索は [sort / search](../../STL/sort-search.md)
- 更新のない区間和は [累積和](../../典型/累積和.md)、区間加算をまとめるなら [imos 法](imos法.md)
- 連続区間の両端を単調に動かせるなら [尺取り法](../../アルゴリズム/尺取り法.md)
- 点加算と区間和は [Fenwick Tree（BIT)](Fenwick%20Tree（BIT).md)
- 点更新や区間更新を伴う集約は [Segtree（セグメント木）](Segtree（セグメント木）.md) と [Lazy Segtree（遅延セグメント木）](Lazy%20Segtree（遅延セグメント木）.md)
- 値の大小関係だけを使う場合は [座標圧縮](../../典型/座標圧縮.md)
