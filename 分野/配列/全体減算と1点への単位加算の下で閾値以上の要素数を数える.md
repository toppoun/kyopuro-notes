# 全体減算と1点への単位加算の下で閾値以上の要素数を数える

## やりたいこと

初期値0の配列で1点に1を足し、全要素が正になったら全要素から1を引く。途中で正の閾値以上の要素数を求める。最大の累積加算数に応じて頻度表を確保できるときに使う。

## 基本的な考え方

各要素への累積加算数を `added[i]`、全体減算の回数を `removed` とし、実値を `added[i] - removed` と表す。`at_least[h]` に累積加算数が `h` 以上の要素数を持つ。1点が `h-1` から `h` に増えたときは、該当する閾値 `h` の個数だけを増やす。

## 実装（C++）

`abc459_c` の形式で `N Q` と `1 x` または `2 y` のクエリを読む。正式例は公式解説に沿った累積個数の別解。照合済みの自作コードは同じ共通オフセットを使い、頻度の区間和を Fenwick Tree、実値0の要素を添字集合で管理する。正式例では、単位加算で越える閾値が1つという条件を使い、両方の処理を `at_least` にまとめる。[AtCoder 公式解説](https://atcoder.jp/contests/abc459/editorial/20982)

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;
    vector<int> added(n, 0), at_least(q + 1, 0);
    at_least[0] = n;
    int removed = 0;

    for (int query = 0; query < q; ++query) {
        int type, value;
        cin >> type >> value;
        if (type == 1) {
            const int height = ++added[value - 1];
            ++at_least[height];
            if (at_least[removed + 1] == n) ++removed;
        } else {
            const int threshold = value + removed;
            cout << (threshold <= q ? at_least[threshold] : 0) << '\n';
        }
    }
}
```

## 実装の要点

- 初期状態は全要素0なので `at_least[0] = N`。加算先が新たに越える閾値を更新し、`at_least[removed+1] == N` なら全体減算を1回記録する。
- 前のクエリ処理後には実値0の要素が必ずある。全要素が正に変わるとき、今加算した要素が実値1になったため、1回減算すれば実値0が再び存在する。
- 実値 `y` 以上の条件は、累積加算数 `y+removed` 以上の条件に等しい。

## 計算量・注意点

初期化と全クエリで O(N + Q) 時間、追加メモリ O(N + Q)。実値 `y` 以上の照会は `at_least[y + removed]` を参照する。累積加算数は高々 `Q` なので、それを超える閾値の答えは0。1回に複数を足す場合は越える閾値が複数になる。
