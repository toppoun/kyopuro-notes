# 正方形グリッドを4方向に回して一致させる最小操作数を求める

## やりたいこと

同じ大きさの正方形グリッドを、全体の右90度回転と1マスの変更で目標に一致させる。どちらの操作も1回の費用が1で、任意のマスを目標の値に1回で変更できるときに使う。

## 基本的な考え方

マスを変更してから回転する操作は、先に回転して移動先のマスを変更する操作と同じになる。全ての回転を先にまとめ、0〜3回回した盤面と目標を比較する。回転回数が固定なら、変更すべきマスは不一致の箇所に一致する。

## 実装（C++）

`abc404_b` の形式で `N` と2つの `N×N` の盤面を読む。照合済み実装と同じ4通りを調べ、C++ 例では配列を交換して回転先を再利用する。

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<string> current(n), target(n);
    for (string& row : current) cin >> row;
    for (string& row : target) cin >> row;

    vector<string> rotated(n, string(n, '.'));
    int answer = n * n;
    for (int turns = 0; turns < 4; ++turns) {
        int cost = turns;
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) cost += current[i][j] != target[i][j];
        }
        answer = min(answer, cost);
        if (turns == 3) break;
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) rotated[j][n - 1 - i] = current[i][j];
        }
        current.swap(rotated);
    }
    cout << answer << '\n';
}
```

## 実装の要点

- `current` に現在の向きの盤面を持つ。各向きで回転回数と不一致数の和を計算し、最小値を更新する。4回の回転は元の向きに戻るので省ける。
- 次の向きでは `(i,j)` の値を `rotated[j][N-1-i]` へ移し、盤面を交換する。回転0回で全マスを塗り替える場合でも費用は高々 `N²` のため、初期値に `N²` を使える。

## 計算量・注意点

時間・追加メモリ O(N²)。時計回りは0始まりで `(i,j) → (j,N-1-i)`。`N=1` や回転対称の盤面でも0回を含めて比較する。
