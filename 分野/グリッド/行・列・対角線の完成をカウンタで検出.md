# 行・列・対角線の完成をカウンタで検出

## やりたいこと

正方形の盤面に順に印を付け、最初に1行、1列、主対角線、副対角線のどれかが埋まる手番を求める。各マスへの印付けは高々1回とする。

## 基本的な考え方

行・列・対角線ごとに印の数を持つ。1手ごとに、そのマスが属する線だけを更新する。

## 実装（C++）

`abc355_c` の形式で一辺の長さ `n`、手数 `t`、1始まりの行優先番号を `t` 個読む。番号は1〜`n²` の相異なる整数。`n >= 1` とし、`n²` と手数は `int` に収まる。最初の手番を1始まりで出し、未達成なら `-1` を出力する。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, t;
    cin >> n >> t;
    vector<int> row_count(n), col_count(n);
    int main_diag = 0, anti_diag = 0;

    for (int turn = 0; turn < t; ++turn) {
        int cell;
        cin >> cell;
        --cell;

        const int row = cell / n;
        const int col = cell % n;
        ++row_count[row];
        ++col_count[col];
        if (row == col) ++main_diag;
        if (row + col == n - 1) ++anti_diag;

        if (row_count[row] == n || col_count[col] == n ||
            main_diag == n || anti_diag == n) {
            cout << turn + 1 << '\n';
            return 0;
        }
    }

    cout << -1 << '\n';
}
```

## 実装の要点

0始まりに直した番号を `n` で割った商が行、余りが列になる。`row_count[row]` と `col_count[col]` は常に増やす。主対角線は `row == col`、副対角線は `row + col == n-1`。重複しないマスを数えているため、カウンタが `n` に達すれば、その線の全マスに印が付いたと分かる。各手の直後に判定するので最初の手番が得られる。

## 計算量・注意点

時間 O(n + t)、メモリ O(n)。保存済みPython実装は宣言列をまとめて読み、この例は1手ずつ読む。奇数サイズの中心は両対角線に属するため、`if` を2つ独立に評価する。重複する宣言を許す場合は同じマスの印を再加算せず、手番は元の宣言順で数える。
