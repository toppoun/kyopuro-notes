# 部分列に含まれるかを貪欲に判定

## やりたいこと

文字列 `target` が `s` の部分列として存在するか判定する。離れた位置の文字を選んでもよく、選ぶ位置は左から順に進める。

## 基本的な考え方

`matched` に確定済みの文字数を持つ。`s` を左から走査し、次に必要な `target[matched]` と初めて一致した位置を選ぶ。

## 実装（C++）

`s` と `target` を1行ずつ読み、入力された文字をそのまま比較する。空行も入力できる。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s, target;
    getline(cin, s);
    getline(cin, target);

    size_t matched = 0;
    for (char c : s) {
        if (matched == target.size()) break;
        if (c == target[matched]) ++matched;
    }

    cout << (matched == target.size() ? "Yes" : "No") << '\n';
}
```

## 実装の要点

`k` 文字目を最も早く一致する位置で選べば、他の選び方で `k` 文字目を選ぶ場合以上に、後ろの候補を多く残せる。これを各文字について繰り返して最後まで一致すれば部分列が存在する。空の `target` は始めから一致済みで、連続した同じ文字には別々の位置を1つずつ割り当てる。

### 応用例（ABC349 Cの空港コード）

保存済みコードと候補の例では、英小文字の `s` を大文字化したうえで `s.push_back('X')` し、英大文字3文字の `target` を同じループで照合する。大文字化を加える場合は `<cctype>` をインクルードし、読み込み直後に `for (char& c : s) c = static_cast<char>(std::toupper(static_cast<unsigned char>(c)));` を書く。その後に `X` を追加する。

追加した `X` は最後の1文字にしか使えない。これで元の文字列から3文字を選ぶ場合と、2文字を選んで末尾の `X` を補う場合をどちらも扱える。

## 計算量・注意点

判定ループは時間 O(|S| + 1)、入力文字列を除く追加メモリ O(1)。2行の読み込みは O(|S| + |T| + 1)。`matched == target.size()` を確かめてから添字を使う。空港コードの前処理も最悪時間 O(|S| + 1) で、末尾追加によって文字列の領域を再確保することがある。
