
文字の種類が固定なら配列で数える。

## 小文字

```cpp
array<int, 26> cnt{};

for (char c : s) {
    cnt[c - 'a']++;
}
```

## 大文字

```cpp
array<int, 26> cnt{};

for (char c : s) {
    cnt[c - 'A']++;
}
```

## 数字

```cpp
array<int, 10> cnt{};

for (char c : s) {
    cnt[c - '0']++;
}
```

`map<char, int>` より固定配列の方が単純で速い。
