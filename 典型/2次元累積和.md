
長方形領域の和を O(1) で求める。

`sum[i][j]` = `[0, i) × [0, j)` の合計。

```cpp
vector<vector<ll>> sum(h + 1, vector<ll>(w + 1));

for (int i = 0; i < h; i++) {
    for (int j = 0; j < w; j++) {
        sum[i + 1][j + 1] =
            a[i][j]
            + sum[i][j + 1]
            + sum[i + 1][j]
            - sum[i][j];
    }
}
```

長方形 `[r1, r2) × [c1, c2)` の和。

```cpp
ll res =
    sum[r2][c2]
    - sum[r1][c2]
    - sum[r2][c1]
    + sum[r1][c1];
```

前計算 O(HW)、各クエリ O(1)。
