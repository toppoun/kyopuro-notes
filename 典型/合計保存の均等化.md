
操作で全体の合計が変わらず、最終的に値をできるだけ均等にする問題。

## 最終状態

合計を S、要素数を N とすると

```cpp
ll low = S / N;
ll r = S % N;
```

最終状態は
- `N - r` 個が `low`
- `r` 個が `low + 1`

になる。

つまり、合計が保存されて最大値と最小値の差を1以下にするなら、最終的な値の集合はほぼ合計だけで決まる。

## ABC313 C 型

```cpp
sort(a.begin(), a.end());

ll sum = accumulate(a.begin(), a.end(), 0LL);
ll low = sum / n;
ll high_cnt = sum % n;

ll ans = 0;

for (int i = 0; i < n; i++) {
    ll target = (i < n - high_cnt ? low : low + 1);

    if (a[i] < target) {
        ans += target - a[i];
    }
}
```

1回の操作で「ある要素から1減らして別の要素へ1増やす」なら、足りない分の合計が必要な操作回数になる。

## 覚え方
合計保存 → 最終状態を先に決める → そこへ合わせるための過不足を数える。
