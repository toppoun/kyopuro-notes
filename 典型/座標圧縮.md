
値そのものは大きいが、大小関係と同値関係だけ使いたいときに `0, 1, 2, ...` に詰める。

例:

`100, 5000, 100, 30` → `1, 2, 1, 0`

## 基本

```cpp
vector<ll> xs = a;

sort(xs.begin(), xs.end());
xs.erase(unique(xs.begin(), xs.end()), xs.end());

vector<int> comp(n);

for (int i = 0; i < n; i++) {
    comp[i] = lower_bound(xs.begin(), xs.end(), a[i]) - xs.begin();
}
```

`comp[i]` が圧縮後の値。

## 1個だけ圧縮

```cpp
int id = lower_bound(xs.begin(), xs.end(), x) - xs.begin();
```

## 元の値へ戻す

圧縮後の番号が `id` なら

```cpp
ll x = xs[id];
```

## 使う場面

- 座標が `10^9` まであるが登場する値は N 個だけ
- 値を添字として配列を持ちたい
- 順位・大小関係だけ必要
- Fenwick Tree / Segment Tree と組み合わせたい

計算量 O(N log N)。

## 注意

連続した距離そのものが重要な問題では、単純に番号へ置き換えるだけでは意味が変わることがある。
