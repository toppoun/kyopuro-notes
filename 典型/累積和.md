
区間和を何度も求めるときに使う。

## 定義

`sum[i]` = `a[0] + ... + a[i-1]`

```cpp
vector<ll> sum(n + 1);

for (int i = 0; i < n; i++) {
    sum[i + 1] = sum[i] + a[i];
}
```

## 区間和

半開区間 `[l, r)` の和。

```cpp
ll range_sum = sum[r] - sum[l];
```

構築 O(N)、各区間和 O(1)。

`sum[i]` は「先頭から i 個分の合計」と覚える。
