
## 3×3の固定ライン

3×3の行・列・斜めのように構造が固定なら、添字計算を頑張るより最初からlineを列挙すると実装が楽。

```cpp
vector<array<int, 3>> lines = {
    {0, 1, 2},
    {3, 4, 5},
    {6, 7, 8},
    {0, 3, 6},
    {1, 4, 7},
    {2, 5, 8},
    {0, 4, 8},
    {2, 4, 6},
};
```

各lineをそのまま回せる。

```cpp
for (const auto& line : lines) {
    for (int v : line) {
        // v はマス番号
    }
}
```

3要素固定なら `set` より `array<int, 3>` の方が単純で軽い。

## N×Nの固定ライン

行N本、列N本、対角線2本の合計2N+2本を生成する。

### 2次元座標で管理する場合

```cpp
vector<vector<pair<int, int>>> lines(2 * n + 2);

for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        lines[i].push_back({i, j});
        lines[n + i].push_back({j, i});
    }
    lines[2 * n].push_back({i, i});
    lines[2 * n + 1].push_back({i, n - 1 - i});
}
```

使用例。

```cpp
for (const auto& line : lines) {
    for (auto [r, c] : line) {
        // grid[r][c] を処理
    }
}
```

### 1次元のマス番号で管理する場合

```cpp
vector<vector<int>> lines(2 * n + 2);

for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        lines[i].push_back(i * n + j);
        lines[n + i].push_back(j * n + i);
    }
    lines[2 * n].push_back(i * n + i);
    lines[2 * n + 1].push_back(i * n + n - 1 - i);
}
```

生成時の時間・空間計算量はともに O(N²)。

## 添字の早見表

すべて0-indexed。

| 種類 | 2次元座標 | 1次元添字 |
|---|---|---|
| i行目 | `(i, j)` | `i*n+j` |
| i列目 | `(j, i)` | `j*n+i` |
| 主対角線 ↘ | `(i, i)` | `i*(n+1)` |
| 副対角線 ↙ | `(i, n-1-i)` | `(i+1)*(n-1)` |

## 対角線の直接走査

ラインの列挙が不要なら、そのまま走査する。

```cpp
for (int i = 0; i < n; i++) {
    // 主対角線 ↘
    grid[i][i];

    // 副対角線 ↙
    grid[i][n - 1 - i];
}
```

主対角線は行番号と列番号が等しい。
副対角線は行番号と列番号の和が N-1。

## 対角線の判定

座標 `(r, c)` が対角線上にあるか判定する。

```cpp
bool main_diag = (r == c);
bool anti_diag = (r + c == n - 1);
```

Nが奇数の場合、中央のマスは両方の対角線に属する。

## 任意の斜めをグループ化

中央を通る対角線だけでなく、すべての平行な斜めを管理したい場合。

- 右下方向 ↘：`r - c` が一定
- 左下方向 ↙：`r + c` が一定

```cpp
vector<vector<int>> diag(2 * n - 1);
vector<vector<int>> anti(2 * n - 1);

for (int r = 0; r < n; r++) {
    for (int c = 0; c < n; c++) {
        diag[r - c + n - 1].push_back(r * n + c);
        anti[r + c].push_back(r * n + c);
    }
}
```

`r - c` は負になる可能性があるため、`n - 1` を加えて添字を非負にする。

各方向に2N-1本の斜めが存在する。

## 覚え方

- 固定で小さい構造 → 一般式より直接列挙
- 固定ラインを繰り返し使う → 事前に生成
- 主対角線 ↘ → 行と列が等しい
- 副対角線 ↙ → 行と列の和が N-1
- 平行な斜め ↘ → 行と列の差が一定
- 平行な斜め ↙ → 行と列の和が一定
