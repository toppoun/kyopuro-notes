# C - Bingo 2

## 問題概要

`N T` と宣言する番号 `A_1 ... A_T` を読む。行優先で1〜`N²` の番号を振った `N×N` 盤面に順に印を付け、行・列・2本の対角線のいずれかが初めて埋まる手番を1始まりで求める。達成しなければ `-1`。`2 <= N <= 2000`、`1 <= T <= min(N², 2×10^5)`、宣言番号は1〜`N²` の相異なる整数。

## 解法の概要

各行・各列・2本の対角線について、印の数をカウンタで管理する。1手で増えるのは印を付けたマスを含む線のカウンタだけ。各線の長さは `N` で、番号の重複がないため、カウンタが `N` になればその線が完成する。更新直後に検査することで最初の手番を返せる。時間 O(N + T)、カウンタは O(N)、保存済みコードは宣言列も保持するので全体のメモリは O(N + T)。

主分類は [グリッド](../../分野/グリッド/グリッド.md)。

## 問題固有の実装ポイント

- 番号から1を引いた `v` の座標は `(v//n, v%n)`。主対角線は `r == c`、副対角線は `r + c == n-1`。
- 奇数サイズの中央マスは両方の対角線に属するので、2つの `if` を独立に評価する。
- 番号の重複が許される派生問題では、既に印のあるマスを無視するなど、同一マスを2回数えない仕組みが要る。その場合も答えは元の手番で数える。
