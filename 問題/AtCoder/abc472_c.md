# C - On a Diet

## 問題概要

`N M K` と各日のカロリー `A_1,...,A_N` を読む。今日のおやつを含めた直近 `M` 日の摂取量が `K` 以下なら食べる。日ごとに `Yes` / `No` を出力する。`1 <= M <= N <= 2×10^5`、`K <= 10^15`、`1 <= A_i <= 10^9`。

## 解法の概要

差分配列を0で初期化し、左から累積する。0始まりの `i` を判定する時点で、`imos[i]` は直前までに採用したうち今日の窓に残るカロリーの合計。`imos[i] + A_i <= K` のときだけ、今日の採用を将来の判定日 `[i+1,i+M)` に加算する。更新先は現在位置より先だけなので、差分を順に累積しても各日の判定時に必要な値がそろう。時間 O(N)、追加メモリ O(N)。

主分類は [配列](../../分野/配列/配列.md)。

## 問題固有の実装ポイント

- 今日の分は判定式に直接足す。過去の採用分は `i+M` 日目から窓の外になる。終了位置が `N` を超えるときは取り消しの記録が不要。
- `M=1` のとき将来への寄与区間は空。`K` と等しい合計は採用する。累積値と `K` は `long long` で持つ。
