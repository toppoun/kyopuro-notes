# C - Drop Blocks

## 問題概要

`N Q` とクエリを読む。`1 x` はマス `x` にブロックを1個積み、全マスが正になったら全マスから1個ずつ取り除く。`2 y` は実際の高さが `y` 以上のマス数を出力する。`1 <= N,Q,y <= 3×10^5`。

## 解法の概要

実際には全体の高さを更新せず、マスごとの累積加算数 `a[i]` と全体で引いた回数 `offset` を持つ。実際の高さは `a[i]-offset`。累積加算数が `offset` と等しいマスを集合に入れ、加算時にそのマスを集合から除く。集合が空になったら `offset` を1増やし、新しい最小値の集合を作り直す。空になった直前の加算先はちょうど `offset+1` に届いたので、全体減算を1回行えば実高さ0のマスが再び存在する。照会は Fenwick Tree 上で `y+offset` 以上の累積加算数の頻度の和を求める。

主分類は [配列](../../分野/配列/配列.md)。

## 問題固有の実装ポイント

- 頻度表は累積加算数を添字にする。加算前の正の値の頻度を1減らし、更新後の値の頻度を1増やす。照会の `y >= 1` により初期の累積加算数0は登録しなくてよい。
- 集合の作り直しは1回 O(N) だが、そのたびにブロックを `N` 個消したことになる。消した総数は積んだ総数以下なので、全作り直しの時間は合計 O(Q)。固定の頻度表の長さを `U=10^6` として、時間 O(N+U+Q log U)、追加メモリ O(N+U)。
- 実高さの照会下限は `y+offset` で、その値を含む。照合済み実装では入力の第2値を先に1減らし、Fenwick Tree の和の左端で1を戻している。
