# C - Truck Driver

## 問題概要

`N A B` と長さ `N` の `a`・`b` からなる文字列 `S` を読む。`a` が `A` 個以上、かつ `b` が `B` 個未満の連続部分文字列を、開始位置と終了位置の組として数える。`1 <= A,B <= N <= 3×10^5`。

## 解法の概要

`a` と `b` の累積個数をそれぞれ作る。0始まりの左端 `l` を固定し、半開区間 `[l,r)` の `a` が初めて `A` 個以上になる右端 `first_a` と、`b` が初めて `B` 個以上になる右端 `first_b` を二分探索する。どちらの個数も `r` を進めると減らないので、有効な右端は `first_a <= r < first_b` を満たすものに限る。各 `l` の `max(0, first_b - first_a)` の和が答えになる。時間 O(N log N)、追加メモリ O(N)。

主分類は [文字列](../../分野/文字列/文字列.md)。

## 問題固有の実装ポイント

- 空区間を表す `r=l` ではどちらの閾値にも達しない。番兵の `N+1` は条件を満たす右端が存在しない場合に返す値で、累積和の添字には使わない。
- `b` がちょうど `B` 個ある右端は範囲から外す。`first_b=N+1` なら右端 `N` まで許す。`a` が足りないときと、`b` の上限に先に達したときの寄与はいずれも0。
- C++ では答えが最大 `N(N+1)/2` なので `long long` で持つ。

## 自作コード

Inbox で照合した Python の実装を確認した。提出との対応とジャッジ結果は未確認。

文字を `a` なら1、`b` なら0に読み替え、`sa` と `sb` へ累積する。各左端について二つの探索区間を `[l,N+1]` で初期化し、`a` の充足と `b` の閾値到達をそれぞれ探す。

公式2サンプルと、片方の文字しかない場合、閾値に届かない場合、32ビット整数を超える答え、短い文字列の全区間を数えた結果を照合した。
